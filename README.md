# 🙏 Smriti (स्मृति) - A Digital Tribute to Teachers

> *"A candle loses nothing by lighting another candle."*

**Smriti** is a personal digital tribute wall dedicated to the teachers who shaped my journey. Built with love, gratitude, and modern web technologies, this project is my way of saying "Thank You" to those who lit the path of knowledge.

---

## 🌟 About

Every student has that one teacher whose words echo through their life. **Smriti** (meaning "Memory" in Sanskrit) is a tribute platform where I honor and remember the teachers who made a difference in my life.

This isn't just a website — it's a digital diary of gratitude, capturing:
- Their wisdom and advice
- Cherished memories
- The impact they had on my life
- A way to send heartfelt thank you notes

---

## ✨ Features

### Phase 1: Foundation
- 🎨 Beautiful, responsive single-page design
- 🌅 Elegant hero section with Sanskrit quotes
- 👥 Teachers grid with photo cards
- 📱 Fully mobile-responsive
- ✨ Smooth scroll animations
- 🎭 Premium UI with warm color palette

### Phase 2: Detailed Profiles
- 📖 Individual teacher profile modals
- 💭 Best advice and favorite memories
- 🎯 Teaching style and personality showcase
- 🌱 Impact and legacy section
- 📸 Rich visual storytelling

### Phase 3: Interactive Gratitude
- ✉️ "Send a Thank You Note" feature
- 📧 Direct email integration via EmailJS
- 🎨 Beautiful HTML email templates
- ✅ Form validation and feedback
- 🔒 Secure and spam-protected

---

## 🛠️ Tech Stack

- **Frontend:** HTML5, CSS3, JavaScript (ES6+)
- **Styling:** Tailwind CSS
- **Animations:** CSS Animations + Intersection Observer
- **Email Integration:** EmailJS
- **Fonts:** Playfair Display (Headings), Inter (Body)
- **Hosting:** Vercel / GitHub Pages
