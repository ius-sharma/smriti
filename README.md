# Smriti

A clean and minimal website built to preserve and showcase memories beautifully.

## 🌐 Live Demo

👉 https://smritiius.vercel.app/

## ✨ Features

- Minimal & modern UI
- Responsive design
- Smooth user experience
- Fast loading
- Clean layout

## 🛠️ Tech Stack

- HTML
- CSS
- JavaScript
- Vercel (Deployment)

## 🚀 Getting Started

Clone the repository:

```bash
git clone https://github.com/your-username/smritiius.git
```

Go to the project folder:

```bash
cd smritiius
```

Open `index.html` in your browser or run it using Live Server.
